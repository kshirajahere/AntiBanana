# 🚀 Quick Installation Guide

## Install in 3 Steps:

### 1️⃣ Start Backend
```bash
cd backend
py main.py
```
✅ Server running at http://localhost:5000

### 2️⃣ Load Extension
1. Open Chrome → `chrome://extensions/`
2. Enable **Developer mode** (top-right toggle)
3. Click **"Load unpacked"**
4. Select the `chrome-extension` folder

### 3️⃣ Use Extension
- Click the 🍌 icon in Chrome toolbar
- Upload an image in any tab
- Get instant results!

---

## 🎯 4 Main Features:

| Tab | Feature | What it does |
|-----|---------|--------------|
| 🔍 **Detect** | Deepfake Detection | Analyze if image is fake/real |
| 🛡️ **Protect** | Image Protection | Add MMHI protection to images |
| 📜 **C2PA** | Provenance | Verify content credentials |
| 💡 **Explain** | AI Explainability | See why AI made its decision |

---

## ⚙️ Settings (Bottom of popup)
- Backend URL: `http://localhost:5000` (change if needed)
- Click **Save** after changes

---

## 🐛 Not Working?

**Server Offline (Red dot)?**
- Make sure backend is running: `py main.py`
- Check: http://localhost:5000/health

**Extension won't load?**
- Enable Developer mode first!
- Select the correct `chrome-extension` folder
