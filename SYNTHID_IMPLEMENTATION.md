# SynthID Detection - Implementation Summary

## What is SynthID?
SynthID is Google's invisible watermarking technology that embeds imperceptible watermarks in AI-generated images. It operates in the frequency domain and is designed to be resistant to common image manipulations.

## How It Works

1. **Image Upload**: User uploads image for detection
2. **Backend Processing**: 
   - SynthIDDetector analyzes frequency domain
   - Checks for Google's watermark patterns
   - Returns detection results
3. **Frontend Display**:
   - Shows SynthID detection card in Details tab
   - Highlights if watermark found
   - Displays confidence and strength metrics
   - Lists in technical analysis summary

## Detection Indicators

### Watermark Detected
- Amber-highlighted card
- "Detected" badge
- Shows generation method (e.g., "Google Gemini Imagen")
- Displays confidence and watermark strength percentages

### No Watermark
- Standard muted styling
- "Not found" status in technical analysis
- Indicates image was not generated by Google AI

## Video Support
- SynthID detection currently works for **images only**
- Video frames can be analyzed individually
- Each frame gets SynthID detection
- Implementation in VideoDeepfakeDetector handles frame-by-frame analysis
